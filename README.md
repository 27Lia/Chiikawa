# 🐾 HangingPet

### 치이카와 친구들이 내 맥북 화면 위에서 산다

맥북 바탕화면 위를 치이카와 · 하치와레 · 우사기 · 모몽가가 자유롭게 돌아다니는 데스크탑 펫 앱이에요.
클릭하면 캐릭터마다 다른 반응을 하고, 마우스로 집어서 옮길 수도 있어요.

## ✨ 뭘 할 수 있나요

- 🚶 **자유롭게 돌아다니기** — 가만히 있다가 가끔 화면을 가로질러 걸어다녀요.
- 🖱️ **드래그로 옮기기** — 마우스로 캐릭터를 집어서 원하는 자리에 놓을 수 있어요.
- 🎯 **캐릭터별 전용 리액션** — 클릭하면 성격에 맞는 고유 반응이 나와요.
  | 캐릭터 | 클릭하면 |
  | --- | --- |
  | 치이카와 | 훅 미끄러졌다가 다시 기어 올라오기 |
  | 하치와레 | 한 바퀴 핑 돌기 |
  | 우사기 | 폴짝 높이 뛰기 |
  | 모몽가 | 날다람쥐답게 옆으로 쓱 활공하기 |
- ⚙️ **설정 창에서 전부 켜고 끄기** — 드래그, 클릭 반응, 자동 배회, 캐릭터별 보이기/숨기기, 항상 위로 고정 여부까지 체크박스로 조절하고 저장돼요.
- 🖥️ **바탕화면 전체를 캔버스로** — 투명 오버레이라서 다른 앱을 써도 캐릭터가 그 위/아래로 자연스럽게 공존해요.

## 📦 설치

1. [Releases](../../releases)에서 DMG 파일을 받거나, 아래 빌드 방법으로 직접 만들어요.
2. DMG를 열고 `HangingPet.app`을 `Applications`로 드래그해요.
3. 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면, 앱 아이콘을 **우클릭 → 열기**로 실행하면 돼요.

## 🛠️ 직접 빌드하기

```bash
git clone <this-repo-url>
cd hangingpet
pnpm install

# 실행 (개발 모드)
npm start

# DMG 빌드
npm run dist
```

빌드된 DMG는 `release/` 폴더에 생성돼요.

## 🧩 동작 방식

- `Electron` 기반의 투명 오버레이 창이 화면 상단에 떠서 캐릭터를 그려요.
- 캐릭터가 없는 빈 공간은 클릭이 그대로 바탕화면/다른 앱으로 통과돼요 (캐릭터 위에서만 마우스 이벤트를 받음).
- 메뉴바 트레이 아이콘에서 "항상 위로 고정 / 바탕화면에 붙이기", "로그인 시 자동 실행", "설정 열기"를 제어할 수 있어요.

## ⚠️ 저작권 안내

캐릭터 이미지는 포함되어 있지 않아요. `assets/characters/` 폴더에 본인이 보유한 이미지를 넣어서 사용해주세요. 치이카와는 나가노(ナガノ) 작가의 저작물입니다.
